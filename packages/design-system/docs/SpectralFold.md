# SpectralFold

The landing's one full-color element: a deterministic SVG contour sculpture on grained charcoal, built live from `apps/landing/src/components/SpectralFold.tsx`.

**Use** at most one per page, always captioned as an illustration. It represents no research data.

**The consumer provides**
- `id`: unique, used for the SVG title and description.
- `study`: `'overview' | 'identity-dissolution' | 'persona-integrity'`. Changing it morphs the contours; reversals start from the current frame.

Pointer motion tilts the figure (mouse only). **Turn the fold** rotates it 90°. Under reduced motion every change is immediate. Animation pauses offscreen and when the tab is hidden.
