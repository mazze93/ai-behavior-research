03 / STUDY DESIGN

Compare complete prompt packages

Each model receives all four conditions with the same sampling settings. Conversations begin fresh, execution order is randomized, and the full requests and responses are preserved.

The controls separate some effects of creative writing and supplied imagery. They do not isolate self-reference perfectly: prompt length, framing, and task differ.

OPEN QUESTION

Cross-model convergence

Not measured by this pilot. Shared imagery appears in the prompts, so its recurrence alone cannot establish independent convergence.

Research context: Berg, de Lucena & Rosenblatt (2025) report self-reference effects in a different study. This project is not a direct replication. Read the arXiv abstract ↗
