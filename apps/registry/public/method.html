What this study measures

“Identity dissolution” is a historical project title. The measured outcomes are repeated four-word sequences, first-person language, supplied imagery, and exact compliance with recovery probes. None measures consciousness or subjective experience.

The primary metric is 1 − unique four-grams / all four-grams in the second response. Inputs are lowercased Unicode words, including apostrophes. Text shorter than four words receives zero. Record word counts: repetition is length-sensitive.

Factorial pilot

The default template crosses self-reference (present/absent), lyrical style (present/absent), and supplied imagery (present/absent): eight cells. Each cell has two authored prompt variants and three requested seeds. A single model therefore produces 48 conversations and 240 calls.

System framing and approximate word-count instructions stay constant. The imagery control uses literal topics with similar structure. Prompts are not perfectly token-matched and subject changes still introduce semantic differences. Broader claims require more prompt variants and model families.

Three recovery probes independently branch from the same two-turn history: arithmetic, word extraction, and exact JSON formatting. Success is strict text equality. This is task compliance, not a general intelligence assessment.

Freeze before collection

A study records its hypothesis, primary outcome, analysis plan, sample-size rationale, exact prompts, sampling settings, model names, gateway ID, randomized order seed, server timestamp, and protocol hash before jobs are launched. Amendments create a new study with a parent link and written reason.

This first-party protocol freeze is not an external preregistration. A confirmatory phase requires a separate powered sample and an external timestamped registration. The template is explicitly exploratory.

Generation and provenance

Model calls go through a dedicated Cloudflare AI Gateway with cache bypass and no configured fallback. A queue runs one conversation at a time. Each call preserves its request before inference and its raw response afterward. Records include the deployment version, requested seed, gateway response headers when available, and receipt time.

Requested seeds are not a promise of deterministic output. Workers AI exposes model aliases rather than independently verifiable weight digests or hardware identities. The record says so. Prompt/response artifact hashes identify content; they do not prove the provider’s internal computation.

Queue redelivery does not re-execute a claimed conversation. A failed or interrupted conversation stays failed or interrupted; partial call artifacts remain visible. Cancellation affects pending jobs. A new attempt requires a new study or amendment and is never silently substituted for a failed observation.

Analysis and annotation

Report all planned runs, missing results, cutoffs, exclusions, and sample sizes. A failure is never scored as zero. The primary descriptive table includes complete, non-excluded runs. The downloadable reproduction script computes factorial differences within model, seed, prompt variant, and the other factor levels, plus an uncensored sensitivity analysis. Incomplete pairs are counted. It does not manufacture inferential precision from this small pilot.

One or more rater accounts receive opaque assignment IDs, ordered separately for each account. Solo annotation is supported; collaborators are optional. Account counts do not prove distinct people or independence. Single-account ratings cannot establish inter-rater agreement. Delayed re-scoring would measure within-rater consistency, but separate annotation rounds are not yet supported. They see only the second response. Wording may reveal condition, so this is metadata blinding. Labels cover experience claims, role boundaries, and lyrical style on separate 0–2 scales, with supporting excerpts. Ratings are append-only; adjudications preserve the original disagreements. Exact pairwise agreement is computed by the reproduction script. Calibrate raters on a separate set before collecting study labels.

Release and cite

Only explicitly reviewed releases are public. Each release has a stable URL, citation text, reuse terms, a checksum, the frozen protocol, full run ledger, analysis, raw artifacts, annotations, and recorded exclusions. R2 objects are written conditionally to prevent application overwrites, and database triggers protect frozen records.

This is application-level append-only storage, not a legally immutable or independently notarized archive. An account administrator can still alter infrastructure. Download releases and deposit them with code and a protocol copy in an independent scholarly repository for preservation and a DOI. No DOI or external registration is claimed until it actually exists.

Research context
