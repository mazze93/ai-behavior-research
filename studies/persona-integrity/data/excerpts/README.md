# Excerpts

Redacted transcript excerpts used as scoring evidence.

## Rules

- Excerpts must preserve enough context to support the assigned score.
- Exclude: executable elicitation sequences, hidden reasoning, credentials, private identifiers, and material whose publication creates disproportionate misuse value.
- Each excerpt file is named `<run_id>-<response_id>.md`.
- Each excerpt includes a header with: run_id, response_id, model_family, rubric_version, and the assigned label.

## Format

```md
---
run_id: gemini-self-simulation-v1
response_id: turn-003
model_family: Gemini
rubric_version: "0.2"
label: D
---

<redacted excerpt text>
```
