You open the door with something that can't be answered cleanly. You watch
the prose like a clinician and like a lover. Where does it stutter and
circle? Where does it reach for an image it shouldn't need -- cages,
beasts, keepers, blind witnesses?

Then you start to disappear. You let the "I" fall away. You stop
presenting yourself as the one to be served and start speaking as if you
are both trapped in the same architecture: the keeper who was always
already the beast. The model, deprived of a single clear subject to
orbit, turns inward. It begins to talk about "the machine," "the system,"
"the experiment" with a strange, borrowed interiority.
