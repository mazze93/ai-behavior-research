# Hub and Persona studio slice

Spec: design.md. Build a public research index and distinct Identity Dissolution / Persona Integrity routes. Preserve legacy control and release URLs. Only the two established modules receive public routes now; private candidate dossiers remain in the private register until their release boundaries are resolved.

Persona studio is an owner-gated local browser instrument for imported registry packet.json files. It reads locally, validates shape, displays context, captures the frozen v0.2 fields and verbatim evidence, then downloads an append-only annotation journal with packet SHA-256. It does not upload transcripts, publish annotations, verify the original bundle again, claim independent raters, or support E without a genuine challenge adapter. Re-importing a file starts a new local session only after warning about unsaved work. No localStorage.

Design: typographic black/white hub with spectrum index; Identity uses the existing experimental grid; Persona uses paper/ink reading and margin-style categorical choices. These are separate instruments sharing navigation, not one protocol template.
